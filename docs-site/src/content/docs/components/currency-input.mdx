title: TkxCurrencyInput
description: Locale-aware currency input — INR lakh/crore grouping, JPY/KRW zero-decimal, 20 currencies, min/max clamping.
---

```tsx
import { TkxCurrencyInput } from 'tekivex-ui';

<TkxCurrencyInput
  label="Income"
  value={income}
  onChange={setIncome}
  currency="INR"
/>
```

A formatted-numeric input that **understands currency grouping rules per
locale**. INR shows `1,23,456` (Indian lakh/crore), USD shows `123,456`
(thousands), JPY/KRW show no decimal places, etc.

## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `number \| null` | — |
| `onChange` | `(v: number \| null) => void` | — |
| `currency` | ISO-4217 code | `'USD'` |
| `min` / `max` | `number` | unclamped |
| `precision` | `number` | derived from currency (JPY=0, USD=2, etc.) |
| `showSymbol` | `boolean` | `true` |
| `label` | `string` | — |

## Supported currencies

INR · USD · EUR · GBP · JPY · CNY · KRW · CAD · AUD · CHF · SGD · HKD ·
NZD · ZAR · BRL · MXN · TRY · RUB · AED · SAR.

(20 in total — extending the map is a one-liner if you need more.)

## Accessibility

- Real `<input>` with `<label>`, `aria-label`, `aria-describedby` for hint
- Currency symbol prefix is decorative — uses `aria-hidden="true"`
- Min/max clamping happens on `change`, not on every keystroke
