against WCAG 2.1 AAA criteria, fully typed, and tree-shakeable. A third-party

## Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `defaultCountry` | `string` |  | Initial country (ISO 3166-1 alpha-2, lowercase). Defaults to "in". |
| `value` | `string` |  | Controlled value (E.164, e.g. "+919876543210"). |
| `defaultValue` | `string` |  | Initial digits (without country code). For uncontrolled use. |
| `onChange` | `(payload: PhoneChangePayload) => void` |  | Fires on every keystroke and country change. |
| `onValid` | `(payload: PhoneChangePayload) => void` |  | Fires when the input loses focus, only if `valid`. |
| `label` | `string` |  | Visible label above the input (required for WCAG compliance). |
| `placeholder` | `string` |  | Placeholder shown inside the input. Defaults to a country-specific example. |
| `disabled` | `boolean` |  | Disable input + picker. |
| `required` | `boolean` |  | Mark required for screen readers. |
| `id` | `string` |  | Optional id; auto-generated if omitted. |
| `name` | `string` |  | Optional name (form submission). |
| `extraCountries` | `PhoneCountry[]` |  | Optional list of additional countries to merge with the built-in set. |
| `className` | `string` |  | Optional className on the root `<div>`. |
| `style` | `CSSProperties` |  | Optional inline style on the root `<div>`. |

## Accessibility

- Keyboard navigation supported on all interactive elements
- `:focus-visible` outline at 2px (theme-token `primary`)
- ARIA roles and properties applied per WAI-ARIA 1.2
- Respects `prefers-reduced-motion`
- Minimum 44×44 touch target where applicable
