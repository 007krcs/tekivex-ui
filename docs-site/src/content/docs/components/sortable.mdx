---
title: TkxSortable
description: Drag-and-drop reorderable list — keyboard-accessible (Space to grab, ↑↓ to move, Enter to drop).
---

```tsx
import { TkxSortable } from 'tekivex-ui';

const [items, setItems] = useState(['One', 'Two', 'Three']);

<TkxSortable
  items={items}
  onReorder={setItems}
  renderItem={(item) => <div>{item}</div>}
/>
```

A reorderable list. Mouse/touch users drag; keyboard users press
**Space** to grab the focused item, **↑/↓** to move it, **Enter** to drop,
**Escape** to cancel. Built on the native HTML5 Drag and Drop API — no
external dep.

## Props

| Prop | Type | Notes |
|---|---|---|
| `items` | `T[]` | unique-keyed array |
| `onReorder` | `(next: T[]) => void` | required |
| `renderItem` | `(item: T, index: number) => ReactElement` | required |
| `getKey` | `(item: T) => string` | default `String(index)` |
| `direction` | `'vertical' \| 'horizontal'` | default `'vertical'` |
| `disabled` | `boolean` | default `false` |

## Accessibility

This is one of the few sortable lists that's actually keyboard-usable:

| Key | Action |
|---|---|
| `Tab` | Focus an item |
| `Space` | Grab the focused item ("picked up") |
| `↑` / `↓` | Move it one slot |
| `Enter` | Drop it at the new position |
| `Escape` | Cancel — restore original order |

Status changes are announced via `aria-live="polite"`:
"Picked up Item 2 of 5" / "Item 2 moved to position 4 of 5".
