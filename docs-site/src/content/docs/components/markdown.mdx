import { TkxMarkdown } from 'tekivex-ui';

<TkxMarkdown source={`
# Hello

- Item two

[Link](https://example.com)
`} />
```

## Supported syntax

- **CommonMark**: headings, paragraphs, emphasis, lists, blockquotes,
  inline code, code blocks, links, images, hr
- **GFM tables**:
  ```md
  | Column A | Column B |
  |----------|----------|
  | Cell 1   | Cell 2   |
  ```
- **GFM task lists**: `- [x] done` / `- [ ] todo`
- **Strikethrough**: `~~deleted~~`
- **Auto-linking**: bare URLs become anchors

## Security

Every Markdown source string passes through SecurityCore before parsing:

- HTML tags are stripped (no embedded `<script>`)
- URLs go through `sanitizeHref()` — `javascript:` and `data:` schemes
  blocked
- Image `src` allowed only for `http`, `https`, `data:image/*`
- Unicode homoglyph + bidi-override characters removed

This makes `TkxMarkdown` safe for **untrusted user content** (forum posts,
comments, profile bios) — XSS-resistant by default.

<Aside type="caution" title="Server-side validation still required">
  Even with SecurityCore, you should rate-limit and length-cap submissions
  on the server. SecurityCore prevents XSS but not abuse.
</Aside>

## Code highlighting

```md
```js
const x = 42;
console.log(x);
```
```

Renders with token colouring. Pass `highlightTheme="dark" | "light"` to
override the auto-detection.

## Custom link target

```tsx
<TkxMarkdown
  source={src}
  linkTarget="_blank"   // automatically adds rel="noopener noreferrer"
/>
```

## Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `source` | `string` | yes | Markdown source. |
| `linkTarget` | `'_self' \| '_blank'` | | Defaults to `_self`. |
| `highlightTheme` | `'dark' \| 'light' \| 'auto'` | | Defaults to `auto` (follows ThemeProvider). |
| `allowImages` | `boolean` | | Defaults to `true`. Disable for ultra-safe contexts. |
| `maxLength` | `number` | | Truncate input. |
