```tsx
import { TkxNumberInput } from 'tekivex-ui';

<TkxNumberInput
  label="Quantity"
  min={1}
  max={99}
  value={qty}
  onChange={setQty}
/>
```

## Step + precision

```tsx
<TkxNumberInput min={0} max={1} step={0.1} precision={1} />
<TkxNumberInput min={0} max={100} step={5} />
```

`precision` controls how many decimal places are displayed; `step` controls
the increment per click/keypress.

## Currency

```tsx
<TkxNumberInput
  label="Price"
  value={price}
  onChange={setPrice}
  format="currency"
  currency="USD"
  locale="en-US"
/>
```

`format="currency"` uses `Intl.NumberFormat` for locale-aware grouping
and the right currency symbol.

## Indian numbering (lakh / crore)

```tsx
<TkxNumberInput
  label="Annual income"
  value={salary}
  onChange={setSalary}
  format="currency"
  currency="INR"
  locale="en-IN"
/>
{/* renders 1,23,456 instead of 123,456 */}
```

## Hold-to-repeat

The `+` and `−` buttons accept a press-and-hold gesture: after a 400ms
delay, they repeat at 60ms intervals. Useful for fast adjustment of large
ranges. Localised `aria-label`s ("Increment" / "Decrement") follow the
active locale.


## Accessibility

- `role="spinbutton"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`
- Stepper buttons get localised `aria-label`s
- Keyboard:
  - **Arrow Up / Down** — increment / decrement by `step`
  - **Page Up / Down** — increment / decrement by `step * 10`
  - **Home / End** — jump to min / max
- Mouse wheel support (opt-in via `wheelStep` prop)
- Mobile: native numeric keyboard via `inputMode="decimal"`

## Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `value` | `number` | | Controlled value. |
| `onChange` | `(value: number) => void` | | Value change. |
| `min` / `max` | `number` | | Bounds. |
| `step` | `number` | | Defaults to `1`. |
| `precision` | `number` | | Decimal places shown. |
| `format` | `'decimal' \| 'currency' \| 'percent'` | | Number formatter. |
| `currency` | `string` | | ISO 4217 code (USD, EUR, INR…). |
| `locale` | `string` | | BCP 47 locale for formatting. |
| `wheelStep` | `boolean` | | Enable mouse-wheel adjustment. |
| `size` | `'sm' \| 'md' \| 'lg'` | | |
