`tekivex-ui` ships **99 components** across nine families. Each is
self-tested against WCAG 2.1 AAA criteria, fully typed, tree-shakeable,
and covered by the 1,798-test suite. A third-party AAA audit is on the
roadmap, not completed. The sidebar lists every page alphabetically — this
index groups them by intent so you can find the right primitive when you
don't yet know its name.

## By family

### Primitives (single-purpose UI)
Alert, Avatar, Badge, Breadcrumb, Button, Card, Checkbox, Chip (Tag),
Divider, Empty, Icon, Image, Logo, Pagination, Progress, Radio, Result,
Segmented, Skeleton, Spin, Title, Toggle, Tooltip.

### Form inputs
Autocomplete, ColorPicker, CurrencyInput, DatePicker, FileUpload, Form,
FormField, Input, NumberInput, OTP, PhoneInput, Rating, Select, Slider,
Toggle.

### KYC + identity (Indian + international)
AadhaarInput (Verhoeff-validated), AddressInput (PIN lookup), KycInputs
(PAN, Voter ID, Driving Licence), PhoneInput (E.164, 50 countries).

### Layout + navigation
Affix, Anchor, AppBar, BottomNav, ConfigProvider, Drawer, Layout
(Header / Sider / Content / Footer / Row / Col), Masonry, Menu, SpeedDial,
Tabs, Toolbar, Tour, Typography.

### Display + content
Accordion, Carousel, Clock, Markdown, OrgChart, RichTextDisplay, Statistic,
Stepper, Table, Tag, Timeline, Watermark.

### Overlays + feedback
Modal, Popover, Snackbar, Toast (ToastProvider), Tour.

### Data-heavy widgets
Cascader, DataGrid, List, Mentions, Sortable, TransferList, TreeView.

### Real-time (timer-driven)
LiveFeed, LiveLog, LiveMetrics, RealTimeChart.

### AI-native
AIChatBubble (streaming chat with sanitisation), AIConfidenceBar
(colour-coded model confidence), AIThinking (dot / pulse / wave / orbit
indicators), Chat.

### Charts (free, no Pro tier)
AreaChart, BarChart, LineChart, PieChart.

### Media + creative
Confetti, ImageEditor (crop / rotate / filters), QRCode, SignaturePad,
VideoPlayer.

### Commerce + fintech
Checkout (multi-step), CurrencyInput (lakh/crore + 20 currencies),
PaymentButton (Stripe / Razorpay / PayPal), Subscription helpers.

### Utility / infra
Captcha (Turnstile / hCaptcha / reCAPTCHA), Command (Cmd-K palette),
FontProvider (35-locale lazy fonts), Playground, SEO (JSON-LD / OpenGraph),
ThemeBuilder.
