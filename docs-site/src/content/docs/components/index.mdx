`tekivex-ui` ships **78 components** across primitives, complex widgets,
AI-native, and real-time families. Every one is WCAG 2.1 AAA, fully typed,
and tree-shakeable.

This index is a placeholder — individual component pages are being migrated
from the legacy demo site to MDX over the v2.7 cycle. Until then, the
existing docs at the [interactive demo](https://ui.tekivex.com/#/components/button)
remain the canonical reference for component-level details.
