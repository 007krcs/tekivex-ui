## Sibling count

<PaginationCompact client:load />

Controls how many pages on each side of the current page are shown:

```tsx
<TkxPagination total={1000} pageSize={10} siblingCount={1} />  {/* default */}
<TkxPagination total={1000} pageSize={10} siblingCount={2} />  {/* wider */}
<TkxPagination total={1000} pageSize={10} siblingCount={0} />  {/* compact */}
```

When the gap is too large, an ellipsis (`…`) renders instead of consecutive
page numbers.

## With first/last buttons

```tsx
<TkxPagination total={500} pageSize={10} showEdges />
```

The first/last buttons are useful for very large data sets. They share
the localised "First page" / "Last page" `aria-label`.

## Localisation

Pagination renders the "Showing X–Y of Z items" line, "Page N" labels for
buttons, and "Previous page" / "Next page" `aria-label`s — all from the
active locale, with English fallbacks for the optional fields.

## Accessibility

- Renders as `<nav aria-label="Pagination">`
- Disabled buttons get the native `disabled` attribute (not just visual)
- Active page button has `aria-current="page"`
- Each page button gets `aria-label="Page N"`
- Edge buttons (first/last) hidden when `showEdges={false}`

## Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `total` | `number` | yes | Total item count. |
| `pageSize` | `number` | | Defaults to `10`. |
| `page` | `number` | | Controlled current page (1-based). |
| `defaultPage` | `number` | | Uncontrolled initial page. |
| `onChange` | `(page: number) => void` | | Page change callback. |
| `siblingCount` | `number` | | Pages on each side of current. Defaults to `1`. |
| `showEdges` | `boolean` | | First/last buttons. Defaults to `true`. |
| `showPageSize` | `boolean` | | Render page-size dropdown. |
| `pageSizeOptions` | `number[]` | | Defaults to `[10, 25, 50, 100]`. |
| `size` | `'sm' \| 'md' \| 'lg'` | | Defaults to `md`. |
