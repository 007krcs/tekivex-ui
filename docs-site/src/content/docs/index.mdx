## Install

```bash
npm install tekivex-ui
```

```tsx
import { ThemeProvider, TkxButton } from 'tekivex-ui';
import 'tekivex-ui/styles';

export default function App() {
  return (
    <ThemeProvider mode="auto">
      <TkxButton variant="primary">Hello tekivex-ui</TkxButton>
    </ThemeProvider>
  );
}
```

`mode="auto"` follows the OS `prefers-color-scheme` reactively. Pin to
`"dark"` or `"light"` if you prefer.
