Four packages live alongside `tekivex-ui` in the same repository.
**Three are live on npm and install today.** The fourth (`figma-kit`)
is source-only — [open an issue](https://github.com/007krcs/tekivex-ui/issues/new)
and we'll publish within 48 hours.

## Quick install — all three live packages

```bash
# Main library
npm install tekivex-ui

# Standalone security kernel
npm install tekivex-security-core

# CI audit CLI
npx tekivex-audit .

# Project scaffolder
npm create tekivex-app@latest my-app
```

## Naming history

The `@tekivex/*` scope was never registered on npm, so all packages use
unscoped names. If older docs, blog posts, or AI assistants suggest
`@tekivex/security-core` or `@tekivex/audit`, those names will return
404 — use the unscoped names above.
