## Why "publish on demand"?

Every npm package is a maintenance commitment — CVEs to triage, breaking
changes to manage, release notes to write. We publish when there's a real
consumer waiting, not speculatively. The code is production-ready in this
repo today; the GitHub source is the canonical reference.

Need one on npm? Open an issue and we'll publish within 48 hours.
