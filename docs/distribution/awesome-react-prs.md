## How to PR an awesome-list (etiquette)

1. Read the contributing guidelines first — most have a strict format
2. Open the PR with **just one addition** — bundle multiple = rejected
3. Include a screenshot or link to the live site
4. Most maintainers want at least 100 GitHub stars OR 1000 npm downloads/week
   before accepting — be patient if rejected, re-apply in 3 months
