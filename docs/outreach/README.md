# Outreach drafts — ready to send

This directory contains **ready-to-send email drafts** for the two outreach
tracks blocking the marketing launch:

1. **WCAG audit firms** — sign a SOW so the AAA claim becomes defensible
   (`drafts/audit/`)
2. **Design partners** — land one regulated-industry logo + quote
   (`drafts/partners/`)

## How to use this directory

Each `.md` file under `drafts/` is one email, pre-personalized, ready to
copy-paste into Gmail. The header block at the top of each file contains:

- **To:** the recipient address (or "find on company contact page" if I
  couldn't determine it from public info)
- **Subject:** the exact subject line
- **mailto:** a one-click deep-link that opens your default mail client with
  subject + body pre-filled

Open `drafts/index.html` in a browser to see all drafts as clickable
mailto links — fastest way to fire them all in one session.

## Workflow (target: one session, 90 minutes)

1. Open `drafts/index.html` in your browser
2. For each draft:
   - Click the mailto link → Gmail opens with everything pre-filled
   - Personalize the [BRACKETED] fields (1-2 minutes each — usually just adding
     a name and a company-specific reference)
   - Hit Send
   - Tick the box in `STATUS.md`
3. After all sends: monitor `novaai0401@gmail.com` for replies, file each in
   the partner's or firm's named subfolder
