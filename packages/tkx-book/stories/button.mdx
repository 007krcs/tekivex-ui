# TkxButton — docs

`TkxButton` is the canonical action element. Variants, sizes, color
schemes, and a loading state — all in a single component.

## When to use

- A primary action on a form (`variant="primary"`)
- A secondary or destructive action (`colorScheme="danger"`)
- An inline link-style trigger (`variant="link"`)

## When NOT to use

For navigation that changes URL, use `<TkxButton as="a" href="...">` or
just an `<a>` tag — buttons should perform actions, links should change
location.

## Variants explained

| Variant | Use |
|---|---|
| `primary` | The single most-important action on the screen |
| `secondary` | Supporting actions next to a primary |
| `outline` | Non-destructive, equal-weight actions |
| `ghost` | Subtle, e.g. inside a card or tooltip |
| `link` | Inline action that reads as a link |

## Loading state

When `loading={true}`, the button is `aria-busy` and `disabled`.
The label stays readable to screen readers; the spinner is `aria-hidden`.

## Accessibility

- 44×44 minimum touch target on `size="md"` and above
- `:focus-visible` outline at 2px (configurable via theme)
- `aria-pressed` when used as a toggle (set `pressed={true}`)
- Disables all pointer events when `disabled` — never visually-only
